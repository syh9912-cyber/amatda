## 이번 재설계의 핵심 원칙

**한 문항의 5개 답변은 그 월령 아이가 모두 똑같이 할 수 있어야 하고, 차이는 오직 "어떻게/어디로"(스타일)여야 한다.**

기존 설문의 결함: 답변마다 요구 능력이 달랐다. 예를 들어 "뛰어다녀요"는 18개월 이후 능력인데
"서서 봐요"는 12개월이면 가능하다. 아직 못 뛰는 13개월 아이는 활동형 답을 고를 수가 없어
활동형이어도 분석형으로 판정된다. 즉 기질이 아니라 **월령**이 측정되고, 같은 아이를 3개월 뒤
재검사하면 기질이 바뀐 것처럼 나온다.

→ 이번엔 문항마다 **공통 능력**을 명시해 다섯 답변이 같은 능력선에 있는지 검산했다.
적대적 검수에서 **능력혼입 77건**이 지적되어 전부 수정 반영했다.

# 적용 전 검토가 필요한 사항

1. **재검수 미실시** — 수정본은 지적사항을 반영했으나, 수정 후 2차 적대적 검수는 돌리지 않았다. 적용 전 한 번 더 돌리는 것을 권장한다.
2. **답변 순서 고정 문제** — 현재 코드는 항상 analyst → explorer → harmony → active → sensitive 순으로 노출한다. 부모가 첫 보기를 고르는 경향이 있으면 분석형이 과대 측정될 수 있으므로 문항마다 순서를 섞는 것을 권장한다.
3. **문항 수** — 20문항이 길다는 피드백이 있으면 기질당 3문항(15문항)으로 줄이는 것도 검토 가능하다.

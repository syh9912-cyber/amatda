- **어떤 상황에서 발생하나**: 앱을 켜서 메인 화면에 진입하는 순간, 앱이 자동으로 꺼짐
- **사용자가 실제로 겪는 것**:
  - 🔴 **심각** — 앱이 죽어버림. 다시 켜도 같은 문제 반복될 수 있음
- **추천**: 🔧 **고치는 게 좋음**
- **추천 이유**: 어제만 14회 발생했고 앱이 완전히 꺼지는 심각한 오류입니다. 기기 내부 언어/지역 관련 모듈(ExpoLocalization)이 앱 설치 파일(APK)에 빠져 있어 발생하는 문제로, 앱 파일을 새로 빌드해야 해결됩니다.
- **고친다면 이렇게**:
  - 수정할 파일: `frontend/package.json` + APK 재빌드 필요
  - 수정 방향: `expo-localization` 패키지를 프로젝트에 추가하고 새 APK를 빌드한 뒤 배포
  - 사장님이 Claude 에게 시킬 말 예시: `"ExpoLocalization 네이티브 모듈 없음 오류 고쳐줘. expo-localization 설치하고 APK 재빌드 필요한지 확인해줘"`

### 2. 앱 첫 실행 시 업데이트 확인에 가끔 실패하는 문제

- **얼마나 자주 발생하나**: 7월 6일까지 총 3번, 사용자 2명에게 발생 (이후 새로운 발생 없음)
- **어떤 상황에서 발생하나**: 앱을 처음 켜는 순간(스플래시 화면), 새 버전이 있는지 서버에 확인하다 실패
- **사용자가 실제로 겪는 것**:
  - 🟢 **가벼움** — 사용자는 전혀 모름. 업데이트 확인만 건너뛰고 앱이 그냥 정상 실행됨
- **추천**: ✅ **그냥 둬도 됨**
- **추천 이유**: 앱 코드에서 이미 이 오류를 잡아서 조용히 넘어가게 처리되어 있습니다. 사용자는 아무것도 느끼지 못하고 앱이 정상 실행됩니다. 4일간 새로운 발생도 없어 일시적 네트워크 문제로 보입니다. Sentry에 기록되지 않도록 조용히 처리하는 코드 개선은 선택 사항입니다.
- **고친다면 이렇게**:
  - 수정할 파일: `frontend/app/_layout.tsx`
  - 수정 방향: OTA 업데이트 확인 실패 시 Sentry에 오류를 보고하지 않도록 오류 필터 추가
  - 사장님이 Claude 에게 시킬 말 예시: `"OTA 업데이트 확인 실패 오류가 Sentry에 계속 잡히는데, 이건 무시해도 되는 오류니까 Sentry에 안 잡히게 수정해줘"`

<details>
<summary>개발자용 세부 정보 (사장님은 안 읽어도 됨)</summary>

- Sentry 링크: https://sy-labs.sentry.io/issues/REACT-NATIVE-R
- 오류 메시지: `Error: Call to function 'ExpoUpdates.checkForUpdateAsync' has been rejected. → Caused by: Failed to check for update`
- 스택 최상단: `construct(native)` in `ExpoUpdates`
- 환경: Android 16, SM-S928N (삼성 갤럭시 S25), 앱 버전 2.9.1+13, 셀룰러 연결
- 처리됨 여부: handled (catch 블록에서 captureError 호출 후 status → 'idle' 복귀)
- 관련 코드: `frontend/app/_layout.tsx:139-143` — catch 블록에서 `captureError` 호출
- OTA 채널: production (CLAUDE.md 권장 채널은 preview)
- 분석: `Updates.checkForUpdateAsync()`가 네트워크 오류 또는 EAS 업데이트 서버 응답 실패로 reject됨. 이미 catch되고 있어 사용자 영향 없음. Sentry 노이즈 줄이려면 catch 블록에서 이 특정 오류는 captureError 제외 처리 가능.

</details>

# 앱 오류 일일 리포트 — 2026년 08월 22일

## ⚠️ 자동화 실행 실패 — 인증 필요

오늘 자동 오류 점검이 실행되었으나, **Sentry(오류 수집 도구) 연결 인증이 만료**되어 오류 조회를 진행할 수 없었습니다.

### 문제 원인
- Sentry MCP 서버: 인증 토큰 없음 → 이슈 조회 불가
- Gmail MCP 서버: 인증 토큰 없음 → 메일 초안 작성 불가

### 해결 방법 (사장님이 해주셔야 합니다)

1. **claude.ai 접속** → 설정(Settings) → 커넥터(Connectors)
2. **Sentry** 커넥터 재인증 (연결 끊김 상태)
3. **Gmail** 커넥터 재인증 (연결 끊김 상태)
4. 재인증 완료 후 다음 자동화 실행 시 정상 동작합니다

또는 Claude Code 인터랙티브 세션(터미널)에서 `/mcp` 명령으로 직접 인증할 수 있습니다.

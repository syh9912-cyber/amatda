# 앱 오류 일일 리포트 — 2026년 08월 07일

## ⚠️ 자동화 실행 불가 — 인증 필요

오늘 자동 오류 점검이 실행되지 못했습니다.

### 원인

Sentry(오류 수집 서비스)와 Gmail 연동이 **인증 만료** 상태입니다.
자동화 세션(사람이 직접 보지 않는 예약 실행)에서는 인증을 새로 할 수 없어서
오류 데이터를 가져오지 못했습니다.

### 해결 방법 (사장님이 직접 하셔야 합니다)

1. **Claude.ai 접속** → 좌측 메뉴에서 **설정(Settings)** 또는 **연동(Connectors)** 항목 클릭
2. **Sentry** 연동 찾기 → **재인증(Re-authorize)** 또는 **연결(Connect)** 클릭
3. **Gmail** 연동 찾기 → 동일하게 재인증
4. 완료 후 이 자동화 작업이 다음 실행 때 정상 동작합니다

또는 **Claude Code 앱(대화형 세션)**에서 `/mcp` 명령어로 인증을 진행하셔도 됩니다.

---

*이 리포트는 인증 오류로 인해 Sentry 데이터 없이 자동 생성되었습니다.*

## 🚨 사장님이 하실 일 (한 번만 하면 이후 자동으로 됩니다)

### 방법 1 — claude.ai 커넥터에서 직접 인증하기 (가장 빠름)

1. [claude.ai](https://claude.ai) 접속 → 설정 → 연결된 서비스(Connectors)
2. Sentry 항목 찾아서 **인증(Authorize)** 버튼 클릭
3. 이후 자동 점검 세션에서도 인증이 유지됩니다

### 방법 2 — 열쇠(토큰) 등록하기

Claude Code 웹 환경에 `SENTRY_AUTH_TOKEN`을 추가하면 다음 실행부터 정상 동작합니다.

1. [Claude Code 웹](https://claude.ai/code) 접속
2. 이 프로젝트의 **설정(Settings)** → **Remote Environment** → 환경 변수 추가
3. 이름: `SENTRY_AUTH_TOKEN` / 값: Sentry 대시보드에서 발급한 토큰

Sentry 토큰 발급 방법: [Sentry 설정 → 인증 토큰](https://us.sentry.io/settings/account/api/auth-tokens/) 에서 `org:read`, `project:read`, `event:read` 권한으로 발급

### 방법 3 — 지금 당장 직접 확인하기

[Sentry 대시보드 바로가기](https://us.sentry.io/organizations/sy-labs/) 에서 직접 오류 현황을 보실 수 있습니다.

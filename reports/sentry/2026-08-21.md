# 앱 오류 일일 리포트 — 2026년 08월 21일

## ⚠️ 자동 점검 실패 — 사장님 확인 필요

오늘 자동 오류 점검을 실행했으나, **Sentry(오류 수집 서비스) 연결 인증이 만료**되어 오류 목록을 가져오지 못했습니다.

Gmail 메일 초안 작성도 같은 이유로 실패했습니다.

---

## 원인

- **Sentry MCP 서버**: 인증(로그인) 필요 — 자동 실행 환경에서는 재인증 불가
- **Gmail MCP 서버**: 인증(로그인) 필요 — 자동 실행 환경에서는 재인증 불가

이 문제는 서비스 자체 오류가 아닌 **연결 인증 만료** 문제입니다.

---

## 사장님이 하실 일

1. [claude.ai](https://claude.ai) 접속
2. **설정(Settings) → 커넥터(Connectors)** 메뉴로 이동
3. **Sentry** 와 **Gmail** 커넥터를 각각 찾아 **재연결(Reconnect)** 클릭
4. 재연결 후 다음 자동 실행 때부터 정상 동작합니다

또는 Claude Code 대화창에서 직접 이렇게 말씀하시면 됩니다:
> "Sentry 오류 점검 한 번 해줘"

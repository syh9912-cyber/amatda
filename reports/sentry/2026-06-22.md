Claude Code 웹 환경에 `SENTRY_AUTH_TOKEN`을 추가하면 다음 실행부터 정상 동작합니다.

1. [Claude Code 웹](https://claude.ai/code) 접속
2. 이 프로젝트 설정 → **Remote Environment** → 환경 변수 추가

Sentry 토큰 발급 방법: [Sentry 설정 → Auth Tokens](https://us.sentry.io/settings/account/api/auth-tokens/) 에서 `org:read`, `project:read`, `event:read` 권한으로 발급

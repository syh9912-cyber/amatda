## ❓ 사장님이 판단할 것

### 1. 동네 엄마 모임 게시글 주변 검색 기능에서 오류가 계속 발생

- **얼마나 자주 발생하나**: 2일 전부터 지금까지 총 20회 발생, 직접 영향 받은 사용자 0명 (서버 내부 오류)
- **어떤 상황에서 발생하나**: 위치 기반으로 주변 엄마 모임 게시글을 조회하는 서버 요청(`/api/mom-group/posts/radius`)이 실행될 때마다 발생합니다.
- **사용자가 실제로 겪는 것**:
  - 🟡 **보통** — 해당 기능(주변 게시글 조회)이 데이터를 불러오지 못하거나 빈 화면이 표시될 수 있습니다.
- **추천**: 🔧 **고치는 게 좋음**
- **추천 이유**: 이틀째 매일 반복되고 있으며, 방치하면 사용자가 늘수록 오류 빈도도 증가합니다. 데이터베이스에 검색 인덱스를 추가하면 해결되는 문제입니다.
- **고친다면 이렇게**:
  - 원인: Firebase 데이터베이스에 `momGroupPosts` 컬렉션의 복합 검색 인덱스(숨김 여부 + 작성 시간)가 없어서 쿼리가 실패합니다.
  - Firebase가 인덱스 생성 링크를 직접 제공하고 있어 클릭 한 번으로 해결 가능합니다.
  - 사장님이 Claude에게 시킬 말 예시: `"mom-group 게시글 반경 검색 Firestore 인덱스 오류 고쳐줘"`

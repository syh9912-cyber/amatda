## ❓ 사장님이 판단할 것

### 1. 외부 웹사이트(sylabs.kr)에서 존재하지 않는 관리자 API를 호출함

- **얼마나 자주 발생하나**: 지난 24시간 동안 3번, 로그인 사용자 0명에게 영향

- **어떤 상황에서 발생하나**:  
  누군가 `https://sylabs.kr` 주소의 웹 브라우저(윈도우 크롬)에서 앱 서버의 관리자 전용 주소(`/api/admin/users`)를 호출했습니다. 서버는 이 요청을 보안 정책(CORS)으로 차단했습니다.

- **추가로 파악된 사항**:  
  - 해당 관리자 주소(`/api/admin/users`)는 **현재 백엔드 코드에 만들어져 있지 않습니다.** CORS를 통과해도 "주소 없음(404)" 오류가 납니다.  
  - `sylabs.kr`은 회사 이름(SY Labs)과 유사한 도메인입니다. SY Labs 웹사이트에서 관리자 화면을 개발 중인 것일 수 있습니다.  
  - 미국 아이오와(클라우드 서버 추정 위치)에서 1분 사이에 3번 연속 요청 → 자동화 테스트 도구일 가능성이 있습니다.

- **사용자가 실제로 겪는 것**:  
  🟢 **가벼움** — 앱 일반 사용자에게는 전혀 영향 없습니다. 서버 보안 정책이 정상적으로 막고 있으며, 해당 API 자체도 아직 없습니다.

- **추천**: ✅ **그냥 둬도 됩니다** — 단, 아래 확인이 필요합니다

- **추천 이유**:  
  보안이 정상적으로 작동하고 있어 정보 유출 위험은 없습니다. 다만 `sylabs.kr`이 회사 내부 관리자 대시보드용 도메인이라면 "의도된 개발 작업"일 수 있으므로, 누가 이 호출을 보냈는지 확인하는 게 좋습니다.

- **사장님이 확인하실 것**:  
  > "혹시 `sylabs.kr` 주소로 앱 관리자 화면(어드민 패널)을 개발 중인 게 있나요?"  
  > - 있다면 → Claude 에게 "어드민 API 만들어줘" 라고 말씀하시면 됩니다.  
  > - 없다면 → 그냥 두시면 됩니다 (보안이 알아서 막고 있습니다).
